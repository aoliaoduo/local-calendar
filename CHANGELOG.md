# Changelog

## 2.1.0

- Added recurring tasks with single-instance edit, delete, and skip support.
- Added task priorities, due-date grouping, drag sorting, filters, and bulk actions.
- Added notification center with target-aware event/task navigation.
- Added tray and system-notification navigation to the matching item.
- Added persisted window bounds, maximized state, and last-view state.
- Unified development, portable, and CLI storage under the local `data` directory.
- Added legacy `%APPDATA%\\local-calendar` migration and notification preferences.
- Added `localcal doctor`, date-based task filters, and multi-ID task commands.
- Added smoke tests covering recurrence, reminders, trash, sorting, and path migration.
